The automated benchmark

While you research, an AI agent gets the same assignment — the same dataset metadata, the same rubric, the same output format — with zero human steering. This page explains what it does and why you can't see its results yet.

How the harness works

  • Same inputs. The agent receives the dataset's title, publisher, description, and URL, plus the risk-assessment prompt and rubric — essentially the Phase 3 prompts with no human in the loop.
  • Agent-agnostic. The framework is designed so we can point it at different models and agents and compare across them.
  • Reasoning is logged. The agent records its thinking as it works, so we can study its process, not just its verdicts — the same way the assessment form asks humans which sources they used.
  • Bounded runs. TEAM DECISION #2 — whether the agent is constrained to roughly human time budgets, or runs until confident, is not settled. Either way: no token furnaces.

Why you can't see its output yet

The whole point is comparing independent assessments. If you saw the agent's answers before submitting yours (or vice versa in a live session), both are contaminated. Results are compared in the group debrief, or in our published analysis for async participants.
