Phase 2

The prompting session

You will now run the same assessment alongside an AI agent, coaching it without telling it the conclusions to draw.

1. Set up your agent

  • Any agent is allowed — ChatGPT, Claude, Gemini, or another.
  • Turn memory off.
  • Turn thinking mode on.
  • Make sure the agent can search the web. This work depends on live sources, so an agent with no internet access will invent its evidence. Turn on web search, browsing, or research mode, and if you're unsure whether it's working, ask the agent to name the URLs it used.
  • Start a fresh conversation for this exercise only.

ChatGPT

Click "Think" in the prompt input field to enable thinking mode. For memory, click Profile > Settings > Personalization, then scroll down to "Memory" and turn off "Enable memory."

Claude

Thinking mode is on by default for all Opus models. Ensure effort is set to "high." For memory, click Profile > Settings > Capabilities and turn off "Search and reference chats" and "Generate memory from chat history."

Anything else

Look for a reasoning, thinking, or research mode and turn it on. If you can't find one, ask a moderator for help.

2. Ground rules

Do

  • Interact like you're training the agent.
  • Stay neutral: ask for changes to its method, not its result.
  • Keep the "I like… / please try…" feedback structure.
  • Deviate small amounts from the prompts if another line of queries renders better results, but note that you did so.
  • Please feel free to ask the agent to consider more precise information, such as the specific unit division or years.

Do not

  • Deviate too far from the prompts as provided — you don't want to turn this into "guess what I'm thinking, AI…"
  • Nudge the bot toward a particular risk level. It will happily change its answer to please you without improving its analysis.
  • Move between agents or try starting new conversations to illicit different responses.

Work through this loop against its answer:

        
    
          
  1. 
            
              Read the analysis from your own perspective and

              factors? Did it find information but misevaluate it, according to
              your interpretation of the rubric?

  2. 
            
              Give feedback in this format.
              I like _____ about this analysis that _____. Please try
              _____
              [searching particular new sources, considering a particular part

              from the last two years…].
              Does that affect your analysis?
            
          
    3. 
          
  3. 
            
              Repeat several times — you're trying to find
              instructions that generate a higher quality result.

          A warning: the bot will easily detect if you're trying

          neutral as you can — ask for changes to its method rather than its
